# Online Examination System

A web-based **Online Examination System** developed as a BCA project for conducting MCQ-based examinations online.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* PHP
* MySQL
* XAMPP

## Features

### Admin Module

* Admin Login
* Create and manage exams
* Add and manage questions
* View registered students
* View examination results

### Student Module

* Student Registration and Login
* View available exams
* Attempt MCQ examinations
* Submit examination
* View examination results
* View previous results

## Database

The project uses **MySQL** to store and manage:

* Student information
* Exam information
* Questions
* Examination results

## How to Run the Project

1. Install **XAMPP**.
2. Copy the project folder into:

```text
C:\xampp\htdocs\
```

3. Start **Apache** and **MySQL** from XAMPP Control Panel.
4. Open phpMyAdmin and create a database named `online_exam`.
5. Import `database/online_exam.sql` into the `online_exam` database.
6. Open the project in your browser:

```text
http://localhost/online_exam/
```
